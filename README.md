# Baby Hotline

Дисковой телефон и бумажные записки: https://sherbakovyan7-bit.github.io/babyhotline/

GitHub Pages размещает интерфейс. Настоящие голосовые звонки требуют отдельного Node.js HTTPS-сервера. В настройках сайта оба участника указывают одинаковый адрес сервера. Постоянный сервер пока не размещён; без него кнопка подключения номера не выдаёт.

`47823` воспроизводит выбранный пользователем локальный аудиофайл. Музыка не входит в репозиторий.

Бумажная почта отправляет сообщения через сервер: оба участника подключаются к линии на одном сервере, отправитель указывает шестизначный номер друга, ник и текст. Получатель проверяет входящие каждые две секунды. TURN для текста не нужен. Сервер хранит до 100 входящих записок в памяти на время подключения; после отключения номера или перезапуска сервера они теряются. Это не постоянная история и не сквозное шифрование. Подтверждение отправки означает приём сервером, а не прочтение другом.

Для доставки требуется обновлённый сервер с `/api/messages`. Одной публикации интерфейса на Pages недостаточно. Новая доставка пока не проверена на двух устройствах.

Сервер: Node.js 20+, `npm start`. Для размещения задайте HOST, PORT, PUBLIC_ORIGIN; HTTPS обеспечивается reverse proxy. Для связи через разные сети может понадобиться TURN_URL, TURN_USERNAME, TURN_PASSWORD. На самом GitHub Pages сервер не запускается.
