# Baby Hotline

Дисковой телефон и бумажные записки: https://sherbakovyan7-bit.github.io/babyhotline/

GitHub Pages размещает интерфейс. Настоящие голосовые звонки требуют отдельного Node.js HTTPS-сервера. В настройках сайта оба участника указывают одинаковый адрес сервера. Постоянный сервер пока не размещён; без него кнопка подключения номера не выдаёт.

`47823` воспроизводит выбранный пользователем локальный аудиофайл. Музыка не входит в репозиторий. Записки хранятся в браузере, не доставляются другим людям.

Сервер: Node.js 20+, `npm start`. Для размещения задайте HOST, PORT, PUBLIC_ORIGIN; HTTPS обеспечивается reverse proxy. Для связи через разные сети может понадобиться TURN_URL, TURN_USERNAME, TURN_PASSWORD. На самом GitHub Pages сервер не запускается.
